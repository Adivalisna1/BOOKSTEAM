================================================================
  BOOKSTEAM — CARA MENJALANKAN & MEMATIKAN WEB
================================================================

PRASYARAT
---------
- Docker Desktop sudah terinstall dan SEDANG BERJALAN (cek di taskbar)
- Node.js sudah terinstall (cek: node -v di terminal)


================================================================
  CARA MENJALANKAN (PERTAMA KALI)
================================================================

LANGKAH 1 — Buka Terminal, masuk ke folder project
----------------------------------------------------
  cd "C:\Users\adiva\OneDrive\Dokumen\test project"


LANGKAH 2 — Jalankan SEMUA (Frontend, Backend, Database, Redis)
---------------------------------------------------------------
  docker compose up -d --build

  Tunggu sampai semua container statusnya "Started" atau "Healthy".
  Cek status:
  docker compose ps


LANGKAH 3 — Jalankan Migrations (SEKALI SAJA, tidak perlu diulang)
-------------------------------------------------------------------
  docker compose run --rm migrate


LANGKAH 4 — Buka Browser
-------------------------
  Frontend  : http://localhost:3003
  API       : http://localhost:3002
  Health    : http://localhost:3002/health


================================================================
  CARA MENJALANKAN (SELANJUTNYA — tidak perlu build ulang)
================================================================

Buka Terminal:
  cd "C:\Users\adiva\OneDrive\Dokumen\test project"
  docker compose up -d


================================================================
  CARA MEMATIKAN
================================================================

Stop Semua (Frontend, Backend, Database, Redis):
  cd "C:\Users\adiva\OneDrive\Dokumen\test project"
  docker compose down

  CATATAN: Data di database TIDAK terhapus.
           docker compose down hanya menghentikan container.


================================================================
  RESET TOTAL (hapus semua data, mulai dari awal)
================================================================

  docker compose down -v

  PERINGATAN: Perintah ini menghapus database beserta semua data!
              Setelah ini kamu perlu jalankan migrate lagi.

================================================================
  TROUBLESHOOTING
================================================================

Error: port already in use
  -> Cek port yang dipakai: netstat -ano | findstr :3002
  -> Ganti port di docker-compose.yml dan backend/.env

Error: Cannot connect to Docker
  -> Pastikan Docker Desktop sudah dibuka dan running

Error: Module not found (frontend)
  -> cd "C:\Users\adiva\OneDrive\Dokumen\test project\frontend"
  -> npm install
  -> npm run dev -- -p 3003

Lihat log backend:
  docker logs booksteam_api --tail 50

Lihat log database:
  docker logs booksteam_db --tail 50
